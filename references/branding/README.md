# Kevin Mok website branding references

These images are local references for the approved kevinmok.com redesign direction.

Direction:
- warm off-white editorial canvas
- tiny lowercase `km` mark
- charcoal serif prose
- muted sans navigation and metadata
- quiet blue underlined links
- fine rules, margin notes, and archive rows
- writing-first, not portfolio-first
- footer should feel anchored to the viewport bottom on short pages
